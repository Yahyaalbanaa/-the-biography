## 📋 نظرة عامة

موقع ويب شخصي احترافي ومتطور يعرض مهارات وخبرات **يحيى خالد نعمان البناء** كمطور برمجيات ومتخصص في تطوير الواجهات الأمامية. الموقع مصمم بعناية فائقة ليعمل بكفاءة على جميع الأجهزة مع دعم كامل للغة العربية والإنجليزية والتبديل بين الثيمين الفاتح والداكن.

## ✨ المميزات الرئيسية

### 🎨 التصميم
- ✅ **تصميم عصري واحترافي** يواكب أحدث اتجاهات تصميم الويب
- ✅ **واجهة مستخدم سلسة** مع تأثيرات تفاعلية جذابة
- ✅ **تدرجات لونية مميزة** لكل قسم من أقسام الموقع
- ✅ **أيقونات Font Awesome** لتحسين التجربة البصرية
- ✅ **خطوط Google Fonts** (Cairo للعربية، Roboto للإنجليزية)

### 🌓 دعم الثيمات
- ✅ **الثيم الفاتح (Light Mode)** - خلفية بيضاء مريحة للعين
- ✅ **الثيم الداكن (Dark Mode)** - تصميم عصري يحافظ على راحة العين
- ✅ **تبديل سلس وسريع** بين الثيمات بنقرة واحدة
- ✅ **حفظ الاختيار تلقائياً** في المتصفح (LocalStorage)
- ✅ **زر عائم** للتحكم السريع في الثيم

### 🌍 دعم اللغات
- ✅ **اللغة العربية (RTL)** - بدعم كامل لاتجاه الكتابة من اليمين لليسار
- ✅ **اللغة الإنجليزية (LTR)** - بدعم كامل لاتجاه الكتابة من اليسار لليمين
- ✅ **تبديل فوري** بين اللغتين دون الحاجة لإعادة تحميل الصفحة
- ✅ **ترجمة شاملة** لجميع عناصر الموقع
- ✅ **حفظ اللغة المختارة** تلقائياً

### 📱 التجاوب الكامل
- ✅ **متوافق مع جميع الأجهزة** (Desktop, Tablet, Mobile)
- ✅ **تخطيط مرن** يتكيف مع جميع أحجام الشاشات
- ✅ **قائمة تنقل محمولة** للشاشات الصغيرة
- ✅ **صور وعناصر متجاوبة** بشكل كامل
- ✅ **تجربة مستخدم ممتازة** على الأجهزة المحمولة

### 🎭 التأثيرات والحركات

- ✅ **Hover Effects** - تأثيرات تفاعلية عند مرور الفأرة

## ⚙️ التخصيص

### تغيير الألوان
افتح ملف `css/style.css` وعدّل CSS Variables:

```css
:root {
    --accent-primary: #0066ff;      /* اللون الرئيسي */
    --accent-secondary: #0052cc;    /* اللون الثانوي */
    /* المزيد من المتغيرات... */
}
```

### تعديل المحتوى
افتح ملف `index.html` وعدّل:
- النصوص في الأقسام المختلفة
- الروابط الاجتماعية
- معلومات المشاريع

### إضافة ترجمات جديدة
افتح ملف `js/script.js` وأضف لغة جديدة في كائن `translations`:

```javascript
const translations = {
    ar: { /* النصوص العربية */ },
    en: { /* النصوص الإنجليزية */ },
    fr: { /* النصوص الفرنسية - مثال */ }
};
```

## 📋 Overview

A professional and modern personal portfolio website showcasing the skills and experience of **Yahya Khaled Noman Al-Banna** as a Software Developer and Front-End Specialist. ### 🎨 Design
- ✅ **Modern and professional design** following the latest web design trends
- ✅ **Smooth user interface** with attractive interactive effects

### 🌓 Theme Support
